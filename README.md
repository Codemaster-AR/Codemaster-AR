### **Implementation Guide:**

1.  **Stars:** I used `img.shields.io`. It fetches the star count directly from the GitHub API every time the page loads.
2.  **Views:** I used `komarev.com`. This acts as a hit counter that increments whenever someone visits your profile.
3.  **Repos:** Since Markdown is static, the best "dynamic" way to show all repos is via **Pinned Cards** (as shown in the Gallery section) or a manual table that links to the live Shields.io badges.

**Pro Tip:** If you want a list that updates *instantly* when you create a new repo without you doing anything, you would need to set up a **GitHub Action** using a tool like `blog-post-workflow` (configured for repos) to rewrite your README daily.
